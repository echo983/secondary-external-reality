# GWA 世界基础粗审计 v0.6

日期：2026-08-23

## 结论

当前固定小闭环具备较强自洽性，可以开始开放自然语言的“理解与提案”实验，但不足以允许开放式 LLM 直接形成 WorldTruth。准入原则是：**开放表达，封闭因果原语；开放提案，不开放提交权。**

## 七项不变量

| GWA 不变量 | 当前状态 | 主要缺口 |
|---|---|---|
| I1 HardConsistency | 小闭环较强 | 缺少通用提交前试应用与完整 schema |
| I2 ExplanatoryAdmissibility | 未实现 | 尚无解释模型与冲突证据层 |
| I3 QueryIndependence | 局部成立 | 仅 fixture 内的未知值有稳定机制 |
| I4 ProjectiveConsistency | 局部成立 | 未覆盖开放投影和组合闭包 |
| I5 CommitmentMonotonicity | 较强 | 追加日志和失败隔离已成立 |
| I6 CounterfactualStability | fixture 内成立 | 通用未知投影尚无稳定身份与固定机制 |
| I7 MinimalCommitment | 方向正确 | 当前成本是字段计数，不是最小充分依赖闭包 |

T1 CommitBeforeExpose 基本成立；T2 在单进程内成立但缺少跨进程写入边界；T3 只有雏形；T4 主要依赖 renderer prompt，尚非强制信息流边界。

## 已成立的基础

- `ttd` 只表达尝试，不声明结果。
- `world_commits` 是权威事实源，失败尝试只进入非权威审计。
- 追加日志支持重放、重启恢复、世界 basis 校验和审计修复。
- 固定对象域已有实体身份、唯一直接位置、时态关系和包含无环约束。
- LLM 只有生成、陪审和呈现能力，没有数据库提交权。

## P0 风险

1. 目前非法世界增量可能在写入后、下一次重放时才被发现。
2. 关系目标实体、实体类型、属性、谓词和能力尚未统一进入封闭 schema。
3. `stateChanges` 与 `newWorldCommitments` 是两条物化路径，可能表达同一事实却发生分歧。
4. Promise 写队列只覆盖单进程；多进程可能从相同序号同时准备提交。
5. 陪审目前只有一个现实审计角色，且上下文不足以替代确定性世界校验。
6. 最小承诺尚未计算因果、实体和认识依赖闭包。

## 本阶段加固范围

- 写入前在当前权威世界副本上完整试应用候选增量。
- 引入 MVP 封闭 schema，并校验关系两端、类型、属性、值域和谓词。
- 要求实体投影状态变化具有同值的实体属性承诺，形成单一可重放语义。
- 以跨进程单写者锁包围“读取最新序号—试应用—追加”，提交时重检全局版本。

完成后仍不宣称完整实现 GWA；I2、通用 I3/I6、真正的 MSRC 和双验证工位继续作为开放输入阶段的后续门槛。
