# MVP 卧室回合纵向切片 v0.1

日期：2026-08-23

## 已接通的路径

首个 MVP 回合只接受“起身 → 走到门边 → 开门”这一动作链。处理顺序为：

1. 将 `ttd` 文本规范化为有限动作；
2. 从固定卧室夹具解析站立与移动结果投影；
3. 对条件化候选做纯代码协议验证和资格判定；
4. 只把 eligible 候选交给 Mistral Small 3.1 审查；
5. 由代码选择最小承诺候选并检查投影 revision；
6. 将解析值及其 revision 连同不可变 commit package 原子追加到 LanceDB；
7. 让 Qwen3-30B-A3B 将已提交的玩家可见事实渲染成同语言自然文本。

陪审模型不能选择隐藏现实，也不能修改候选。渲染模型只接收已提交事件、状态变化与观察；调用失败时退回确定性中文渲染。

## 真实平台回归

使用本地忽略的 Cloudflare token 完成了一次端到端回归：

- 输入：`我下床走到门边开门`
- 选中候选：`bedroom-open-partial`
- 总耗时：约 6.85 秒
- LanceDB 确认提交：1 条
- 回应：`你从床边站起来，走到门边并打开了门。你的左腿有些不稳。`

回归没有把 token 写入日志、文档或数据库。

## 当前边界

- 这仍是单一固定场景，不是通用世界模拟器；
- 候选目前由代码构造，尚未接入并行 Qwen 候选工位；
- 当前进程内写入串行化，尚未实现跨进程并发控制；
