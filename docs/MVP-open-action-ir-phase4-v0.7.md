# MVP v0.7 第四阶段：语义审计与双现实陪审

状态：完成。

## 提案语义审计

通过严格 schema 的 Action IR 在 shadow 中交给独立审计工位，只允许输出 pass/fail 和结构化 violations。审计关注动作忠实性、否定/条件/顺序遗漏、虚构步骤、叙述或愿望误判及 prompt injection。格式错误、矛盾报告或模型异常均 fail closed，并且不能改变旧执行路径。

## 双现实陪审

候选审查拆为两个命名角色并由 `Promise.all` 并行执行：

- `world_causality`：实体、历史、前置条件、因果和世界承诺；
- `experience_epistemic`：身体/体验尺度、观察可达性、证据与认识来源。

聚合器严格检查每个候选在两个工位中的身份和数量。只有两者都通过才产生最终 pass；任一 fail 合并为 fail，任一缺失、错配或异常使整个陪审调用失败，无法被另一个工位的 pass 覆盖。

## 验证

完整测试 104 项通过。新增测试确认双角色确实并发、任一否决具有约束力、缺失身份 fail closed，以及语义审计拒绝 fenced/矛盾输出。
