# MVP 回合审计计划 v0.4

一次 `ttd:` 输入是一个根回合，可包含多个顺序执行的原子步骤。`world_commits` 仍是唯一 WorldTruth；失败步骤只写入非权威的 `turn_attempts`，绝不产生世界效果。

每个成功提交携带 `rootTurnId`、`stepIndex`、`stepCount`。每个尝试记录原始步骤、成功或失败状态，并在成功时关联提交序号和候选项。首步失败产生零个世界提交和一个失败审计；中途失败保留此前提交，失败步骤只审计，后续步骤不执行。

两个 LanceDB 表目前没有跨表事务。系统先写权威世界提交，再写成功审计；若恰在两次写入间崩溃，可能缺少审计，但不会制造虚假现实，且可从提交元数据补建。

验收范围：单步成功、完整序列、首步失败、中途失败，以及关闭数据库后重开查询。
