# MVP 回合审计自修复计划 v0.5

## 目标

当权威世界提交已经落盘、进程却在成功审计写入前退出时，从 `world_commits` 幂等补建缺失的 `turn_attempts`。

## 规则

- 只补建 `status=committed`；世界提交永远不能证明一次失败。
- 新提交额外保存原始原子步骤 `attemptedTtd`，与现有根回合和步骤元数据一起构成可恢复信息。
- 缺少恢复元数据的旧提交保持原样并计入 skipped，不猜测输入。
- 相同 `attemptId` 的相同审计视为已存在；内容冲突时停止并报错，不覆盖历史。
- 会话在处理新输入前执行一次修复。修复是幂等的，也可显式调用。

## 一致性

修复只从权威表流向非权威表，不反向改变世界。补建记录沿用世界提交行的落盘时间，保证重启后结果稳定。
