# MVP 回合审计 v0.4 结果

日期：2026-08-23

已实现根回合身份、步骤序号和非权威尝试审计。成功步骤在 `world_commits` 中携带 `rootTurnId / stepIndex / stepCount`，并在 `turn_attempts` 中关联提交；失败步骤只有审计记录。

本地测试 70 项通过，覆盖单步、完整序列、中途失败、首步失败、幂等追加和 LanceDB 重开查询。

真实回归通过：普通 SSH 客户端获得 `ttd:` 提示符，输入“我打开抽屉，拿起桌上的钥匙，然后去开门”，由真实 Cloudflare Workers AI 完成陪审与回应。结果为 3 个世界提交、3 个成功审计，同属一个根回合，步骤序号为 0、1、2。

当前诚实边界：两个 LanceDB 表没有跨表事务。权威提交先写，因此极端崩溃最多造成成功审计缺失，不会把失败写成现实。下一版可依据提交元数据自动补建这种缺失审计。
