# 阶段1（内核可行性实验品）正式收尾 v1.0

日期：2026-08-24
性质：决策记录，宣告一个阶段正式结束，不是设计文档。依据 `docs/STATUS-four-stage-maturity-assessment-v1.0.md` §6 的待决策第一条，用户直接确认：现在就收尾，不再补充新验收项。

## 1. 宣告

**阶段1（内核可行性实验品）到此正式收尾。** 成功标准是架构可信度，不是好用/通用/健壮——这条标准已经被反复验证过，继续在新场景上重复验证边际收益已经不高（判断依据见 §4）。之后的工作转向阶段2（正式内核）的边界与契约定义。

## 2. 阶段1 证明了什么

`docs/GWA-larger-architecture-study-after-v0.9.md` 的成功判据：

> 同一个未预写死的世界投影，在不同自然语言、查询顺序和认识路径下，只被规范地解析一次；主体只能从合法证据路径得知它；以后仍可重放、回忆或发现自己记错，而世界过去不被改写。

这条判据已经在多个独立场景里反复验证：
- Query Confluence / Commitment Closure Integrity / Minimal Resolution / Replay Determinism 四类结构化验收检查，全部有正例反例测试（不是只测正常路径）；
- 两个独立的 Free 投影（hallway-1、living-room-1 的 notable_feature）各自走过"首次操作性触及才解析、解析后永不改变"的完整流程，并且互相独立地验证了这一点，证明这不是单一场景的巧合；
- 记忆回忆（会衰减但不改写 WorldTruth）、内涵式承诺重生成保真（脱离提交记录、只靠种子重新推导）、多主体证言（第二个独立认识主体转述，不直接授权 WorldTruth）——三条不同的认识路径分别验证了"认识只能走合法证据路径"这条主张的三个不同侧面。

## 3. 明确不补，且不是遗留待办

以下几项**不是**收尾前需要清空的清单，是"阶段1不需要它们，以后哪个阶段真的用得到再加"的判断本身（核心原则：GWA是服务于作品的理论工具，不是要交的作业，完备度按当前阶段的活儿打分，不按全局 GWA 覆盖率打分）：

- 错误回忆/错误证言（"发现自己记错"）——近期不模拟复杂心理学；
- CausalSelectionBarrier（I3b）独立验证——现在靠生成器设计隐含满足，没有专门检查，是可接受的取舍，不是漏洞；
- Projective Consistency（I4）——现在没有分级投影内容，连测试对象都不存在；
- Zoom/Redirect 查询出口（Q4）、Explanation Model、呈现层 exposure provenance 审计、T5 语义因果类型强制、NPC 自主行为——纯设想，未动工，且都更像阶段2/3该管的事，不是阶段1该补的洞。

## 4. 这次收尾解锁了什么

阶段2（正式内核）现在可以正式开始定义边界和契约，不用再等"阶段1还没收尾"这层顾虑。已经有真实数据支撑的第一批阶段2议题（来自 `docs/PROBE-stage2-pack-loader-v1.0.md` 的探针结果）：
- schema 需要从"给一间卧室量身定做的封闭枚举"变成可扩展的东西；
- 缺一个"实体在某地点里"的关系谓词，而且现有 `located_on` 对这个用例不是语义不贴切，是校验规则会直接拒绝；
- PlaceGraph、`observations: unknown[]`、对外稳定契约——`docs/STATUS-four-stage-maturity-assessment-v1.0.md` §4 已经列过，此处不重复。

阶段2 边界谁来定、什么时候正式定，仍然是待决策，本文档不替用户定。`content-pipeline/sdlpal-import` 分支是否继续往前探也仍待决策。
