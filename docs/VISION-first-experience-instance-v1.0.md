# 第一个体验实例：愿景与方向目标 v1.0

日期：2026-08-24
状态：方向性愿景（未定稿，等待讨论）
性质：不是实施计划，是给未来 Layer C 及以后工作定方向的目标文档；不扩大当前 MVP 的能力承诺。

## 1. 定位

私有、非商业、不公开进入社会或市场的实验性实例。不涉及权利争议的前提是：使用范围仅限个人研究/实验，不做公开分发、不做商业化。这条边界是这份愿景能成立的前提，不是可选项。

## 2. 体验目标

- **文字优先**。生成图片是可能的未来延伸，不在当前范围内讨论。
- **目标是"乱真"，不是"好玩"**——成功标准是世界收束、可信、不出戏，不是娱乐性或关卡设计意义上的"好玩"。这和当前 MVP phase 1"架构可信度优先于可玩性"的立场是一致的，只是把这条立场往前推到了一个具体、有边界的体验设想上。
- **规模受控，二维硬边界地图**——参考量级是《仙剑奇侠传》余杭镇、《怪奇物语》里的小镇那种大小：一个镇子，不是一个国家或无限延展的开放世界。地理范围有硬边界。
- **超进化的"矮人要塞"式体验**——生成式开放行动 + 反馈。核心例子：玩家把体育馆大门锁眼用某种方式弄坏，可能被目击、被告密，后来被审问。这类体验要求：
  1. **具体手法开放，不预设枚举**——胶水、蜂蜜、物理破坏、别的任何听起来合理的手法都该被接受，不该要求玩家从一个预设动词表里选。
  2. **因果结果收敛、封闭**——"锁失效"这个状态转换本身必须是明确的、会被世界记住的既定事实，不能因为描述方式不同而产生不同的世界状态。
  3. **具体手法只在挣得因果角色时才被促升为正式事实**——多数情况下手法只是叙事装饰，不进入 WorldTruth；但如果这次手法会留下可被目击/取证的差异化痕迹（会影响谁被怀疑、谁能作证什么），这部分细节就必须被促升为一个正式的、首次可寻址即解析并永久固定的事实，不能停留在自由文本、每次被问起时重新现场判断。

## 3. 世界与美术素材：复用现成开源游戏资源

第一个实例直接复用打磨多年的开源游戏资源和设定作为种子材料，而不是从零手绘地理和人物设定。候选：`sdlpal`（《仙剑奇侠传》的 SDL 复刻引擎，https://github.com/sdlpal/sdlpal）。

**复用范围，明确分两块：**

- **地理/贴图层——直接复用**。余杭镇的地图形状、建筑布局属于刚性 KV 范畴（墙在哪、房间多大本来就该是刚性的），复用这块不和"哪些该刚性哪些该开放"的原则冲突，是最省力、最值得拿的部分。
- **人物名单/背景设定——作为非刚性叙述层的种子材料复用**。人物的性格、身世、说话方式，落在半结构化实体的自由叙述层，用作 LLM 驱动 NPC 行为/对话时的"人物小传"式提示材料。

**明确不复用：原版剧本、事件触发脚本、演出逻辑。** 原版的"走到某坐标、满足某 flag、触发固定演出"这套是刚性预设范式的典型代表，和这个项目要超越的东西正相反。剧本/事件对这个项目没有用处。

**角色分叉原则**：种子人物（比如王小虎）只借名字和模糊背景设定当起点。这个世界里他第一次被真正操作性触及的那一刻起，历史完全独立分叉，不受原作剧情牵制，此后谁也不会覆盖谁——和一个地点的 Free 投影首次解析后永久固定是同一条纪律（I5/I6），只是应用对象从一个属性值换成了一整个人物的境遇。原作的核心角色（李逍遥、赵灵儿等）不必是这个世界的主角，可以只是背景邻居、路人，甚至可以完全不存在。

## 4. 需要在现有内核之上新建的能力

当前内核（Layer A 完整 + Layer B 五项：PlaceGraph、观察带宽、物理够得着、记忆回忆、内涵式承诺重生成）是这份愿景的地基，不需要推倒重来。但要撑起第 2 节描述的体验，至少需要新建：

1. **多主体 Agent Epistemic Graph**——不再只有 self，每个 NPC 需要自己独立的证据/认识状态。
2. **证言/转述证据类别**，provenance 明确区分于直接观察（P7：语言只确立"谁说了什么"，从不直接授权 WorldTruth）。
3. **最小 NPC 反应/日程机制**——不需要完整戏剧结构求解器，但需要"NPC 基于已知信息，在某个时间点触发某个反应"这个最小闭环（比如"老师后来会来审问"）。
4. **人物间对话/言语行为的最小语法**——现有语义 IR 是对物体动作取向，"审问"这类人与人的交互需要新的一类操作。
5. **Q4 Zoom/Redirect 查询出口**——镇子规模会大量出现"这个人/这个地方还没被具体实例化"的情况，需要一个有代价、有纪律的按需生成策略，而不是要么写死要么拒绝。
6. **PlaceGraph 从平表泛化为真正的图结构**，配合从 sdlpal 提取的地图数据，建一套批量地理内容管线（格式解析、编码转换、实体映射——这块工程量独立于内核开发，值得单独立项）。
7. **半结构化实体状态**：刚性 KV 核心 + 非刚性自由叙述层，及配套的"衍生事实促升"机制——自由文本本身可以随时开放存储，但一旦某个下游逻辑要依赖它衍生出的新事实，那个衍生事实必须走和现有生成器模式相同的纪律（首次操作性触及时解析一次、立刻提交、永不重判），只是生成器从确定性哈希函数换成了非确定性的 LLM 陪审员。
8. **（待定）陪审员一致性验证**——第 7 项如果要真正保证 I6/I4b，"叙事合理性陪审"本身的判决一致性也需要某种检查，现有的 `checkIntensionalCommitmentFidelity`（重新生成比对）这类机械验证对非确定性生成器不适用，需要新思路（大概率只能靠"绝不重判"的程序纪律兜底，而不是靠事后验证）。

## 5. 明确不在第一实例范围内

- 图片生成；
- 完整戏剧结构/宏观叙事张力求解器；
- 经济/程序化城市生成；
- 完整 illocution registry / 复杂社会关系网络；
- 独立的 Explanation Model 层；
- Projective Consistency（多分辨率投影一致性）——除非镇子内容设计确实需要"远观 vs 走近看"的分级描述，否则不主动引入。

## 6. 和 GWA/当前内核的关系

这不是要求完整 GWA。`GWA-larger-architecture-study-after-v0.9.md` 自己已经从完整 GWA 里收窄出一个"Canonical Commitment & Epistemic Kernel"子集；这份愿景是在那个已经收窄过的目标之上，针对"一个具体的、镇子规模的、非刚性文字体验"这一个实例，再做一次有意识的收窄——不是另立体系，是把 Layer C 里最相关的一小部分（证言、多主体、最小反应机制）真正落地，而不是整个 Layer C。

## 7. 已确认的方向决定（2026-08-24）

- **素材授权**：用户已通过正规渠道全款购买正版《仙剑奇侠传》，个人合法持有拷贝，第 3 节的复用方案可以推进，不是空中楼阁。
- **地图/实体数据管线**：不手工搓任何地理/实体数据——一律从 sdlpal 能解析的原版数据里提取，导入转换成这个项目自己要用的表示方式。具体落地格式不预先锁定：如果 sdlpal 的原始表示方式本身够用，就直接沿用；如果不够用，再另找表示方式。格式选择由实际效果驱动，不预先假设。
- **推进节奏**：一步一步走，跨度太大就拆分——延续现在这套"先证明机制、再扩规模"的节奏，不直接跳到镇子规模的整体施工。
- **半结构化实体 + 陪审员（第 4 节第 7、8 项）的立项时机**：判断是不是"很快用得到"，由我来定。**判断结果：不是**——sdlpal 地理/实体数据导入管线（第 4 节第 6 项）是纯刚性 KV 工作，不依赖半结构化实体/陪审员机制；证言/多主体 AEG（第 4 节第 1-2 项，若先做）也不依赖它，两条轴线正交。半结构化实体+陪审员只有在真正开始设计"开放手法、因果收敛"这类具体内容场景（比如糊锁）时才用得上，现在做是提前给一个还没有具体消费场景的机制打地基，容易做出脱离实际用例的形状。**建议留到真正要设计第一个这类场景时再单独立项，现在记在愿景里即可，不提前动工。**
