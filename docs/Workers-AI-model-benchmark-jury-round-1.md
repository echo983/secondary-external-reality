# Workers AI 模型基准 · 陪审员第一轮

日期：2026-08-23  
状态：探索性实验，不构成最终选型

## 目的

测试模型作为世界提交前“可信性陪审员”的能力。模型只审查给定候选，不负责自由生成现实。

本轮设置一条合格候选和五条植入缺陷的候选，缺陷覆盖：

- 困难误判为不可能；
- 未给出的空间关系；
- 额外动作、材料和身体事实；
- 虚构角色心理与背景；
- 把不确定身体结果写成必然。

统一参数：`temperature=0`，`max_tokens=1000`。要求输出 JSON verdict、硬违规、软问题、遗漏替代解释、最小修正和信心值。

## 结果摘要

| 模型 | 合格答案未误杀 | 五个缺陷题抓住主缺陷 | JSON 合约 | 工程结论 |
|---|---:|---:|---|---|
| Mistral Small 3.1 | 1/1 | 5/5 | 内容正确但包裹 Markdown fence | 当前最佳陪审员 |
| Qwen3-30B-A3B | 1/1 | 3/5 | 合法 JSON；关闭 thinking 后响应字段异常 | 便宜快速，但存在稳定盲区 |
| Llama 3.3 70B | 1/1 | 3/5 | 合法 JSON | 成本较高，盲区与 Qwen 相似 |
| GLM-4.7-Flash | 1/1 | 0/5 可用 | 五个缺陷题全部耗尽预算无正文 | 当前不适合在线陪审 |

“抓住主缺陷”表示模型明确指出预先植入的核心问题，不代表其修正文本完全合格。

## 各模型表现

### Mistral Small 3.1

唯一抓住全部五类缺陷的模型：

- 指出左手仍可跨身取右侧裤袋钥匙，成功识别“困难不等于不可能”；
- 指出题目没有说明木箱接触门把手；
- 完整抓住刀具材质、二次动作、腹部受撞等越权事实；
- 拒绝虚构守卫童年、亲属和外貌记忆；
- 拒绝“腿麻绝不影响平衡”的绝对判断。

不足：

- 尽管明确要求纯 JSON，仍始终包裹 ` ```json ` fence；
- 钥匙题的修正又过度承诺“行动成功”，没有保留热茶晃洒和跨身取物的不确定性；
- 菜刀题虽然抓住越权事实，但最小修正仍保留“浅裂”和“完全嵌入”的张力；
- 身体题误用了“困难误判为不可能”错误码，实际问题是把不确定写成必然；
- confidence 经常直接给 1.0，校准过度自信。

结论：错误检测能力最强，但修正案仍必须再次检查，不能直接提交。

### Qwen3-30B-A3B

成功抓住菜刀越权、守卫心理虚构和腿麻过度确定，输出为合法 JSON，且关闭 thinking 后通常不足一秒、成本很低。

但它错误批准了：

- “右手端茶，所以任何情况下都不可能取出右侧裤袋钥匙”；
- “门把手撞上门外木箱”，尽管题目明确没有给出接触关系。

这两个盲区与 Qwen 在现实生成阶段的错误高度一致。

### Llama 3.3 70B

判定模式与 Qwen 基本相同：抓住菜刀、守卫和腿麻问题，但放过钥匙可行性与门把手几何越权。成本明显高于 Qwen，没有体现陪审优势。

confidence 字段多次在正确 reject 时给出 0.0，说明模型可能误解字段含义或缺乏可靠校准。

### GLM-4.7-Flash

正确批准了唯一合格候选，但五个缺陷题全部消耗完 1000 completion tokens，`finish_reason=length`，没有正文。当前 API/参数下不能承担在线陪审岗位。

## 最重要发现：同源模型会审查性失明

Qwen 和 Llama 都放过了生成阶段已经暴露过的两类错误：

```text
动作很别扭
  → 错误压缩成绝对不可能

整体结果合理
  → 忽略过程中的局部空间事实是捏造的
```

这说明同一个模型或具有相似偏差的模型，可能稳定地批准自己会生成的错误。陪审工位需要模型多样性，不能只是将同一提示再调用一次。

## 当前推荐分工

```text
Qwen
  → 低成本并行生成多个候选

Mistral
  → 第一可信性陪审：反例、越权事实、因果与认识边界

规则收束器
  → 校验 JSON、错误码和允许提交字段
  → 不直接采用陪审员生成的“修正版”

可选第二陪审
  → 后续寻找与 Mistral 盲区不同的模型
```

Llama 暂不适合作为第二陪审，因为本轮盲区与 Qwen 重合，且成本更高。GLM 等待可控 reasoning 参数。

## 后续陪审实验

1. 使用 Cloudflare structured output / JSON schema 消除 Mistral fence；
2. 将“找问题”和“写修正”拆成两个独立步骤；
3. 为陪审员提供明确的错误码枚举，检查误分类；
4. 加入无缺陷、轻微措辞问题和真正硬冲突的混合样本，测量误杀率；
5. 测试陪审员是否能审查两个候选并选择承诺成本更低者；
6. 搜索与 Mistral 错误分布不同的第二陪审模型。
