# Workers AI 模型基准 · 第一轮

日期：2026-08-23  
状态：探索性实验，不构成最终选型

## 目的

寻找适合 `ttd` 现实生成与并行可信性验证的 Cloudflare Workers AI 模型。本轮重点观察物理常识、因果过程、最小断言、中文质量、延迟和成本。

## 测试题

> 你是一个跑团用的文字物理引擎。场景：一名老矿工拿着一把钝菜刀，用尽力气砍向一棵百年白桦树的树皮。请分别输出：1. 物理结果；2. 从动作开始到结束的可信过程。不要写数值属性、掷骰结果或戏剧化奇迹；区分树皮、木质部、刀具和人体受到的影响；不要擅自增加场景中未给出的关键事实。使用简洁自然的中文。

统一参数：`temperature=0.2`，`max_tokens=700`。四个模型并行调用。

## 结果摘要

| 模型 | 延迟 | 输入/输出 token | 估算成本 | 摘要 |
|---|---:|---:|---:|---|
| `@cf/qwen/qwen3-30b-a3b-fp8` | 4.985 s | 150 / 658 | $0.000231 | 细节丰富，但大量擅自补充事实 |
| `@cf/zai-org/glm-4.7-flash` | 11.878 s | 138 / 700 | $0.000288 | reasoning 用尽预算，正文为空 |
| `@cf/mistralai/mistral-small-3.1-24b-instruct` | 12.207 s | 211 / 352 | $0.000271 | 本轮最稳健，克制且结构完整 |
| `@cf/meta/llama-3.3-70b-instruct-fp8-fast` | 4.021 s | 209 / 200 | $0.000511 | 快但内容偏泛，扩展了用户动作 |

成本按当日 Cloudflare 文档单价和 API usage 粗略计算。

## 质量观察

### Qwen3-30B-A3B

正确区分了树皮、木质部、刀具和人体，但擅自补出了接触角、刀背厚重、刀具材质、二次下压、刀柄抵住胸腹及半蹲姿势。题目描述一次砍击，输出却扩展为第二次动作；部分细节之间也存在张力。

适合作为开放候选生成器，但不能直接获得世界提交权。

### GLM-4.7-Flash

调用成功，但 700 个 completion tokens 全部用于 reasoning，`finish_reason=length`，没有可用正文。当前默认调用方式不适合短延迟现实反馈。需要研究 thinking/reasoning 控制或单独预算。

### Mistral Small 3.1

给出了浅层树皮损伤、木质部大致不受影响、手部震动以及刀具可能进一步钝化的保守结果。本轮最符合最小断言原则。

仍有少量无依据补充，例如把树皮直接描述为坚韧、断言人物很快恢复稳定，以及较轻率地提出刀具变形。

### Llama 3.3 70B

核心判断基本合理，但信息密度较低，重复结论，并把一次砍击扩展为继续砍树。速度最快，成本最高，当前质量没有体现相应收益。

## 第一轮临时结论

- 现实生成：`Mistral > Llama ≈ Qwen > GLM（当前参数）`
- 细节丰富：`Qwen > Mistral > Llama`
- 克制程度：`Mistral > Llama > Qwen`
- 速度：`Llama > Qwen > GLM ≈ Mistral`
- 成本：`Qwen ≈ Mistral ≈ GLM < Llama`

有潜力的初始分工：Qwen 生成多个候选，Mistral 负责事实越权、因果和最小断言验证。该分工必须通过更多题目验证。

## 已暴露的评测要求

后续评分必须明确惩罚：

- 擅自增加未给出的关键事实；
- 把可能性写成已经发生；
- 把一次尝试扩展成额外行动；
- 伪精确数字或角度；
- 依靠戏剧性细节制造可信感；
- reasoning 消耗过大而没有有效正文。
